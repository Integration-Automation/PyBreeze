8. 視覺化 JSON 編輯
===================

**你會做的事**：把一個 JSON 檔當成樹來修改、看著文字跟著變、復原，並照它原本的排版存檔。

開始之前
--------

:doc:`t01_install_first_launch`。要用的檔案是範例裡的 ``settings.json``。

範例
----

.. literalinclude:: ../../examples/settings.json
   :language: json
   :caption: settings.json

步驟
----

1. 開啟 **Tools > JSON Editor Tab**，按 **開啟...** 並選擇 ``settings.json``。
   **樹狀** 檢視會顯示 ``（文件）``，底下是 ``name``、``servers`` 與 ``retries``。
2. 選取 ``servers`` 並按 **新增**。清單最後會多出一個值為 ``null`` 的伺服器。
   選取它，在 **類型** 下拉選單選 **物件**，再按一次 **新增**：這個物件會多一個叫
   ``new_key`` 的成員。
3. 在 ``new_key`` 上按兩下並輸入 ``host``。它的值是 ``null``，不能直接輸入：
   選取它，在 **類型** 選 **字串**，再在值上按兩下並輸入 ``127.0.0.1``。
4. 選取 ``retries``，在它的值上按兩下並輸入 ``three``。檢視下方的那一行會說這不是
   JSON 的數字，值仍然是 ``3``。改輸入 ``5``。
5. 選取 ``name`` 並按兩次 **下移**：它變成最後一個成員。
6. 切到 **文字** 檢視，刪掉最後的 ``}``：檢視下方的那一行會指出文字從哪裡開始不是 JSON；
   這時切回樹狀檢視會是空的，直到你把大括號補回來。
7. 在任一個檢視按幾次 **Ctrl+Z**：每按一次退回一步，不論那一步是哪個檢視做的。
   **Ctrl+Y** 會重做。
8. 按 **儲存**。

預期結果
--------

做完步驟 5 之後，**文字** 檢視的內容是：

.. code-block:: json

   {
     "servers": [
       {
         "host": "127.0.0.1",
         "port": 8765
       },
       {
         "host": "127.0.0.1"
       }
     ],
     "retries": 5,
     "name": "demo"
   }

- 縮排是檔案原本的兩個空白。原本寫成一行的第一個伺服器，現在和其他部分一樣展開了：
  在樹狀檢視編輯會把整份文字重新寫出，手動對齊的排版不會保留。
- 有未儲存的變更時，檢視上方的檔名後面會有 ``*``；按 **儲存**，或復原到存檔時的狀態，
  它就會消失。
- 有未儲存的變更時，關閉分頁或開啟另一個檔案都會先詢問。

如果不成功
----------

- **新增** 是灰色的：沒有選取任何項目，或文字目前不是 JSON（看檢視下方的那一行）。
- 格子無法輸入：只有成員的名稱，以及字串、數字、布林的值可以直接輸入。陣列的項目沒有名稱；
  ``null``、物件與陣列要透過 **類型** 與 **新增** 來給值。
