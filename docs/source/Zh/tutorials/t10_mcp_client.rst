10. MCP 用戶端
==============

**你會做的事**：設定一個 Model Context Protocol 伺服器、連線到它、在被詢問之後呼叫它的一個工具，
並在這次工作階段的紀錄裡看到這次呼叫。

開始之前
--------

:doc:`t01_install_first_launch`。伺服器是範例裡的一個檔案；任何以本機程式方式啟動的 MCP 伺服器，
用法都一樣。

範例
----

一個最小的伺服器：它從標準輸入一行讀一則 JSON 訊息，並在標準輸出回答。
它提供兩個工具： ``now`` 與 ``add``。

.. literalinclude:: ../../examples/mcp_time_server.py
   :language: python
   :caption: mcp_time_server.py

步驟
----

1. 開啟 **Tools > MCP Client Tab** 並按 **新增...**。
2. 填入伺服器的資料：

   - **名稱**： ``time``
   - **指令**，每行一個引數，第一行是程式：

     .. code-block:: text

        python
        mcp_time_server.py

   - **啟動位置**：你的專案資料夾（ **瀏覽...** ）。

   按 **Save**。
3. 選取 ``time``，按 **連線**。
4. 在 **工具** 頁選取 ``add``。會顯示伺服器的描述與這個工具的 schema，引數會先填好必填的名稱。
   把它們填成：

   .. code-block:: json

      {
        "a": 2,
        "b": 3
      }

5. 按 **呼叫**。會出現一個問題，顯示工具、伺服器，以及實際要送出的引數。回答 **Yes**。
6. 開啟 **呼叫紀錄** 頁，再按 **在報告檢視器開啟**。

預期結果
--------

- 步驟 3 之後，狀態列顯示已連線到 ``tutorial-time-server 1.0.0``：2 個工具、0 個資源、0 個提示。
- 步驟 5 的問題是「要在 time 上呼叫 add 嗎？」，並說明伺服器對這個工具的說法
  （伺服器表示這個工具不會更動任何東西），預設按鈕是 **No**。按 **Yes** 之後，結果框顯示 ``5``，
  狀態列顯示 add 在幾秒內回應。
- **呼叫紀錄** 頁有一列：時間、 ``add``、已回應、秒數。報告檢視器開啟後，有一次叫做 ``time``
  的執行，裡面就是這次呼叫。
- 再呼叫一次 ``add``，在按 **Yes** 之前勾選「以後在 time 上呼叫 add 不再詢問」：從此這個伺服器的這個工具
  不會再詢問，之後的工作階段也一樣。其他工具仍然會問。

金鑰與 token
------------

需要金鑰的伺服器，要用 **環境變數** 把金鑰給它，也就是設定視窗裡的那張表，不要寫在指令裡：
它們的值以圓點顯示，存在 ``~/.pybreeze/mcp_servers.json`` （只有你自己能讀），而且不論出現在哪裡，
都會從日誌檔、錯誤訊息與匯出的工作階段中去除。

隨專案而來的伺服器
------------------

專案可以用資料夾裡的 ``.mcp.json`` 指明它使用的伺服器：

.. code-block:: json

   {
     "mcpServers": {
       "clock": {"command": "python", "args": ["mcp_time_server.py"]}
     }
   }

這樣的伺服器會以「clock（來自這個專案）」列出，而且 **不會** 因為被找到就啟動。
按 **連線** 會先顯示它的指令並詢問；按 **編輯...** 再按 **Save**，它就成為你自己的伺服器。
專案的伺服器如果和你自己的某個伺服器同名，就不會列出：用的是你自己的那一個。

如果不成功
----------

- 顯示無法啟動 MCP 伺服器：指令的第一行必須是 ``PATH`` 上的程式或完整路徑。
  如果找不到 ``python``，請用你的虛擬環境裡 ``python`` 的完整路徑。
- 顯示 MCP 伺服器關閉了連線：程式啟動後又結束了。狀態列的結尾是它記錄的最後一行；
  以這個範例來說，是 **指令** 或 **啟動位置** 裡 ``mcp_time_server.py`` 的路徑不對。
- 呼叫一直沒有回來：按 **取消**。伺服器有設定檔裡指定的秒數（預設 30 秒），超過就放棄這次呼叫。
- 不支援透過 HTTP 連線的伺服器：只支援以本機程式方式啟動的伺服器。
